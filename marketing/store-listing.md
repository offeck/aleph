## Store Listing Tab — English (default)

**Language:** English

**Category:** Accessibility
(The live listing currently says Productivity — switch it. Accessibility is

**Title:**
Aleph: Hebrew/Arabic RTL Fix + Insights Dashboard

**Summary (132 chars max):**
Fix broken Hebrew & Arabic RTL text in Claude, ChatGPT & Gemini — themes, focus mode, and a cross-platform AI usage dashboard.

**Detailed description (copy-paste this):**

Hebrew, Arabic, Persian (Farsi), and Urdu text comes out scrambled in AI chats: right-to-left paragraphs hug the wrong side, periods jump to the start of lines, numbered lists fall apart, and math collides with the text around it. Aleph fixes it — automatically, on Claude, ChatGPT, and Gemini.

WHY ALEPH AND NOT ANOTHER RTL EXTENSION

Aleph detects direction per element from the actual characters — true BiDi handling — so Hebrew paragraphs go right-to-left while English ones stay left-to-right, and nothing is forced. Math (KaTeX/MathJax), code blocks, and inline expressions are isolated so they stay readable inside RTL text, lists and bullet points keep their order, and everything keeps working while the response is still streaming. It is the only extension that does this across all three major AI platforms.

MAKE THE CHATS YOURS

• 14 hand-tuned dark and light themes — from warm dark to high contrast — with per-platform overrides
• Custom fonts for text and code via Google Fonts, including Hebrew- and Arabic-friendly families
• Adjustable font size, line height, paragraph spacing, and chat width
• Focus mode that hides upgrade banners, suggestion chips, and promo clutter — each category toggleable
• Smooth streaming animations (fade-in, typewriter, slide-up, glow) replacing the platforms' defaults
• A built-in mini-game (Snake, Minesweeper) to play while long answers stream in

ONE DASHBOARD FOR ALL YOUR AI USAGE

• See your Claude, ChatGPT/Codex, and Gemini/Antigravity quota meters at a glance — know where your quota went before you hit the wall
• Track time spent, messages sent, and estimated tokens per platform, with hourly and weekly charts
• See your combined AI subscription spend in one place
• Optional Google sign-in syncs your settings and daily usage summaries across devices — counts from multiple devices add up correctly

PRIVATE BY DESIGN

Everything runs and stays on your device. No telemetry, no analytics, no servers reading your chats — conversation text is never collected, stored, or synced. Cloud sync is opt-in, stores only aggregate daily numbers and your settings under your own account, and is protected by published security rules. The entire extension is open source (MIT): github.com/offeck/aleph

Works on all three platforms. Toggle on/off anytime with Alt+Shift+A. Free, no account required.

## Privacy Practices Tab

**Single purpose description:**
Enhances the AI chat platforms Claude, ChatGPT, and Gemini: fixes Hebrew and Arabic-script RTL text direction and provides visual customization (themes, typography, focus mode) plus local usage insights for these sites.

**Host permission justification:**
The extension requires host permissions for claude.ai, chatgpt.com, chat.openai.com, and gemini.google.com to inject content scripts that detect Hebrew and Arabic-script text and apply BiDi fixes, custom themes, usage tracking, and UI modifications directly on these pages. The background service worker also uses these same provider domains to refresh the user's own plan and quota metadata for the popup insights. The daily-cloudcode-pa.googleapis.com host is used only to read the signed-in user's Google Antigravity/Cloud Code quota metadata for the same local quota dashboard.

**Remote code justification:**
No remotely hosted JavaScript or executable code is loaded. Firebase, KaTeX, and all extension scripts are bundled locally. Optional Google Fonts stylesheets may be requested only when the user selects a custom font in settings.

**Are you using remote code?** No

**Data usage compliance:** Check the certification checkbox.

**Data disclosure:** Disclose website content limited to on-page text needed for local BiDi/usage processing, user activity limited to usage insights and provider quota snapshots (stored locally; daily summaries sync to the user's private Firebase account only with optional sign-in, retained 400 days), authentication information limited to optional Google sign-in email and OAuth token use for sync/Antigravity quota reads, and user settings for optional sync. Conversation content is not stored or synced.
