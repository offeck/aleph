# Brand & Positioning — one page (hard cap)

## One-liner

The only extension that makes AI chats readable AND beautiful for Hebrew/Arabic
speakers — RTL fixing + themes + one usage dashboard, across Claude, ChatGPT,
and Gemini.

## Positioning (vs. the field — details in competitors.md §7)

- RTL Responder (20K users): Claude-only, no styling, no math handling. We: 3 platforms + KaTeX/code isolation.
- Gaugr (24K): Claude-only usage meters, no RTL. We: the same meters cross-platform (incl. Codex/Antigravity), plus RTL.
- Chat-Math RTL Fix (4K): math-only. We: math AND general text.
- Nobody spans RTL + styling + multi-platform. That intersection IS the pitch.
- Supersedes competitors.md §10 on usage tracking: we shipped it (v2.8).

## Audiences (in order)

1. Hebrew-speaking students/devs using 2+ AI platforms — the hero persona (broken חדו"א chats)
2. Arabic/Persian/Urdu-speaking devs — same pain, far bigger pool, weakest competition
3. Quota-anxious power users — Claude Code / Codex subscribers watching shared rate limits

## Voice

- Dev-to-dev, first person, specific ("per-paragraph detection from the actual characters"), zero hype words.
- HE: casual, self-deprecating ("נמאס לי, אז בניתי"). EN: technical, BiDi-literate. AR: respectful-direct.
- Always: open source (MIT), free, no data collection, "Disclosure: I'm the author."

## Never

- Claim it fixes Claude Code / Claude Desktop / CLI / VS Code surfaces (it's a web-page extension).
- Trash competitors — praise their niches; the comparison wins on facts.
- More than one (soft) review ask per post; never incentivize reviews.
- Post the same comment across many threads of one venue (one comment per venue).
- Publish aggregates of user data without a privacy-policy disclosure first.

## Proof points (claims defensible from code)

per-element direction from characters · KaTeX/MathJax + code isolated LTR ·
works mid-stream · 14 themes + per-platform overrides · 5h/weekly quota meters
cross-platform · mini-game while answers stream · local-first, zero telemetry · MIT.
